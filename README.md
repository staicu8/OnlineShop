# Online Shop (ASP.NET Core MVC)

Web application project for online shopping workflows.

## Objective
Implement a structured e-commerce application with MVC architecture, business logic layers, and data access.

## Tech Stack
- C#
- ASP.NET Core MVC
- Entity Framework Core (project data layer)
- Razor Views

## Project Structure
- `Controllers/` - request handling and endpoints.
- `Models/`, `ViewModels/` - domain and UI models.
- `Services/` - business logic.
- `Data/` - persistence and DB context.
- `Views/` - Razor UI pages.
- `wwwroot/` - static assets.

## Run Instructions
1. Open `OnlineShop.sln` in Visual Studio or use .NET CLI.
2. Restore dependencies and build.
3. Run the web application.

Using .NET CLI:
```bash
dotnet restore
dotnet build
dotnet run
```

## Scope
Portfolio-ready academic project demonstrating full-stack web fundamentals in .NET.
